# Network Daemon

Асинхронный сетевой демон на Python для ARP сканирования устройств в Локальной сети 
An asynchronous Python network daemon for ARP scanning of devices on the local network
---
- модульная структура основанная на принципах SOLID
- отправка уведомление при обнаружениях новых устройств 
- весь код асинхронный AsyncoIO 
---
- Modular architecture based on SOLID principles
- Sends notifications when new devices are detected
- Entirely asynchronous using Asyncio
---
Запуск только от имени администратора
Must be run as an administrator
